Tecnologias

O projeto usa apenas tecnologias da web padrão, sem frameworks nem bibliotecas.

Stack

Tecnologias usadas
TecnologiaUso no projetoReferência
HTML5 Estrutura semântica, formulários e multimídia. MDN HTML (abre em nova aba)
CSS3 Layout com grid e flex, variáveis, media queries e efeitos de hover. MDN CSS (abre em nova aba)
JavaScript Motor do jogo: objetos, estado, eventos, tempo e aleatoriedade. MDN JavaScript (abre em nova aba)
Git Versionamento do código. git-scm.com (abre em nova aba)
Vercel Deploy do site. vercel.com (abre em nova aba)

Onde cada técnica aparece

  • Objetos: cada enigma é um objeto JavaScript com estado e métodos.
  • Vetores de textos: as frases do formulário de contato, o diário de bordo e a lista de itens.
  • Manipulação de estado: o objeto estado guarda tempo, erros, inventário e energia.
  • Dados aleatórios: as sequências dos minigames e o protocolo do contato.
  • Controle de tempo: o relógio de 5 minutos (setInterval) e a sequência dos fios (setTimeout).
  • Eventos: click, keydown, submit e input.
