Technology

The project uses standard web technologies without frameworks or external code libraries.

Stack

Technologies used
TechnologyRole in the projectReference
HTML5 Semantic structure, forms and media. MDN HTML (opens in a new tab)
CSS3 Grid and flex layouts, custom properties, media queries and hover effects. MDN CSS (opens in a new tab)
JavaScript Game logic: objects, state, events, timing and randomness. MDN JavaScript (opens in a new tab)
Git Code version control. git-scm.com (opens in a new tab)
Vercel Site deployment. vercel.com (opens in a new tab)

Where each technique is used

  • Objects: each puzzle is a JavaScript object with state and methods.
  • Text arrays: the response messages in the contact form, the investigation log and the item list.
  • State management: the estado object stores time, mistakes, inventory and power state.
  • Randomness: the minigame sequences and the demonstration contact reference.
  • Timing: the five-minute countdown (setInterval) and wire sequence (setTimeout).
  • Events: click, keydown, submit and input.
