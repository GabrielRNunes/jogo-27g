A growing portfolio project

Protocolo Kairo is a browser game developed with HTML, CSS and JavaScript, with version control in Git.

The project covers page structure, responsive interfaces, events, game state, timers and regression tests. Accessibility reviews and tools that support reading and calculation are part of this learning process.

Development process

The project received assistance from OpenAI Codex and Anthropic Claude. Learn more at Project Support.

  1. Defining the premise and 10 puzzles.
  2. Modeling objects and game logic in JavaScript.
  3. Building the pages and shared CSS.
  4. Testing, HTML validation and deployment.
