Project Support

While developing Protocolo Kairo, I used support from OpenAI Codexand Anthropic Claude. These AI tools supported the development of this student project.

Why use these tools?

Building a game involves developing ideas, writing code, editing text and testing interactions. AI assistance supported these tasks and helped refine the way the project is presented.

The aim was to support learning: understanding suggestions, trying changes and checking their results in the game.

Codex

Assisted with implementation, code review, writing and interaction improvements. It also helped make the JavaScript easier to follow and develop the binary calculator as a learning aid.
