Items and Mechanisms

Inventory items

Select an inventory item, then select the object you want to use it on. Only one item is selected at a time. Using an item on the wrong object does not count as a mistake.

USB drive

A black USB drive labeled “training”. It holds a file from Kairo and requires a computer with media access enabled.

Access card

A magnetic card marked SRV, used on the server rack reader.

???

Hidden item

Not everything in the suite is in plain sight. A special discovery may change the ending if you escape before time runs out.

Hints

I’m stuck. What should I do?

Read the Investigation log. Every discovered clue is recorded there with the countdown time.

My item does not work on this object

Check that the item is selected (highlighted button) and the object is available. Solved objects have a green outline.
